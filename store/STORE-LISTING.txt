NAME
Video Focus

SHORT DESCRIPTION (max 132 chars)
Keeps video pages focused: removes short-form shelves and recommendation feeds. No UI, no settings to switch off.

DETAILED DESCRIPTION
Video Focus is a deliberately locked extension for shared family or school computers.

It removes short-form video shelves (Shorts) and recommendation feeds from video pages, so the
page shows only what was deliberately searched for.

There is no popup, no options page, no toolbar button and no storage: nothing for the user to
switch off, which is exactly the point.

The extension is deployed by device policy by the machine's administrator.
